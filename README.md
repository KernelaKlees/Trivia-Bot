# Trivia Bot

A simple JavaScript console bot that introduces itself and shares fun coding facts. Built as part of a FreeCodeCamp JavaScript lab.

## How it works
Open the browser console to see the bot's messages.  
All output is generated using variables, template literals, and `console.log()`.

## Files
- `index.html` — minimal page to load the script  
- `script.js` — Trivia Bot logic
